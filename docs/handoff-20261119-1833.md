## 0. 为什么 R97/R98「全 PASS」是错的（本轮最重要结论）

R98 用 `free`/`side` 机位拍 7 张图就判"中段空城未复现"，但**从没用过用户实际开到的 `chase` 车后追尾低机位**。本轮用 chase 机位 z=−600 实拍，左侧一片 #D4C8B8 土黄空地 + 米色远山 + 悬空黑色楼板——用户反馈真实存在。根因不是显隐、不是雾、不是相机，是**几何真的缺一段**：R97 只改 zone 显隐判据、R98 只加护栏，都不造几何，当然没修好。

- 用户截图 z 定位（r99-city 与 r99-capture 交叉核对零分歧）：远处带圆形钟盘 + 金尖拱的是**城门楼 GATE**（z=−358.5，主殿 R39 已拆金日轮、无钟面），车在城内 z≈−600、回头朝 +Z 看城门楼；画面左侧空地 = 世界 +x 侧 faceHalf=15.5 外。
- 空档数学：`cityBlockIndices(20,10)` ⇒ ks=[0,1,2,3,6,8,11,14,16,19]，缺块 10 个 k=[4,5,7,9,10,12,13,15,17,18]；连续空档 92m×4 + 46m×2（**最大连续空档 92m，不是旧档写的 138m——那是块心距，口径已纠正**）。地面铺装连续、殿/塔/连墙整块不生成 ⇒ 露土黄地形。

## 1. 三个细节修复

### P1 空档补街几何（castleKit.ts，+54 行，tri +1440 / DC +0）
`makeInnerCity`（L4081 后）循环外新增确定性补街：对相邻 ks 跨度>1 的每个缺块（全部 10 个），side=±1 补台基 + 殿身（从地面起、前脸严格 |x|=15.5）+ 双坡顶 + 两段连墙（覆盖整块 46m、首尾相接无新缝）。全部进已有 ashlar/wall/roof 桶，不新增桶/mesh。不改采样/keep/护栏、不改显隐/雾/相机。实测 innerCity tri 94,396→95,836（+1440），全显 tri 220,534→221,974（<235k），DC 29 不变。
- 穿模硬约束：补墙内缘严格 15.5，未抄 marble 装饰带（15.0）/金线（15.27）等内凸件（否则车缘 15.5 会嵌入）。

### P2 块角穿模（FreeDrive.ts，corridorCenterHalfWidth 块区分支）
R98 把块角 3m 过渡外端点当抽象面线 15.5 且不扣车半宽 ⇒ 车缘从块心 11.003 涨到角点 **16.503**，嵌入可见角塔大理石基座内缘 14.9 达 1.6m（R98 测试只断言两函数相等，漏检）。改为：dc<3 从 `CITY_CORNER_CAR_CENTER≈13.897` 线性插值到块心 10.0；13.897 = 基座内缘 − 车半宽，基座内缘 = `INNER.faceHalf − 1.2/2 = 14.9`（真源 castleKit.ts:3381 基座裙外扩 1.2，从 r28Layout/VEHICLE import 派生，不写死）。dc=0 车缘恰贴 14.9、dc≥3 仍 11.003（R97 净空）。`corridorHalfWidth` / BOUNDS 逐位不动（CameraRig 依赖）。
- 空档边界本轮**不改**：补街后空档有可见墙，15.5 兜底不再是空气墙。

### P3 撞击硬切 → 冲量瞬态（FreeDrive.ts resolveBounds + step 写回）
定罪：撞侧墙 `slideHeading` 一帧转 Δh≈0.2rad = 1375°/s（26×maxYawRate）+ `wallDecay=0.9` 一次吃 44g，读起来就是"瞬间硬切到漂移"。改为：
- 速度按法向吸收/切向保留矢量分解（`v=sign(v)·hypot(v·fn·(1−decay), v·√(1−fn²))`），斜擦 fn≈0.199 时 speed 19.61（旧版 16.42），不再骤降；
- 新增纯函数 `impactHeadingStep(h,target,τ,dt)`（wrapAngle 最短弧 + alpha 钳 [0,1]），朝向一阶收敛 τ=0.12s：单帧只转 0.0139rad（≈1.6rad/s，maxYawRate 量级），~0.29s 走完 95%；
- `resolveBounds` 增 `impactN=|v|·fn` / `targetHeading`，FreeDrive 增 `wallImpact` 包络，step 写回处同步收敛 beta/yawDyn（消次生硬切）+ 短暂 yawRate/roll 冲击瞬态指数衰减；
- 速度也用 `damp(r.speed, v, 1/IMPACT_TAU, dt)` 提交（否则 free_drift 零油门收敛会红，已实测）；hall 分支本轮不动。
- 新常量 IMPACT_TAU/YAW_GAIN(0.02)/ROLL_GAIN(0.004) 独立于 FREE 灵魂表与 FREE_BODY_DAMPING，摩擦圆/制动力/限速/冗余/路障/热衰减/涡扇契约全不碰。
