- 根因：`YangwangAdapter` 直接 `GLTFLoader.load` 单 40MB GLB，完全绕过 `highDetail` 偏好/取消发布订阅与 ExternalShell 统一 HUD；失败回调只置台账 failed、无文案。

- `src/model/external/ExternalShell.ts`：导出既有 `shellHud` / `clearHudThrottle`，`shellHudProgress` 接受 `'yangwang'`；V800/R7 加载路径逐位未动。
- `src/model/YangwangAdapter.ts`：
  - 加载前门禁：偏好关闭/已取消 ⇒ 零 fetch、台账 `cancelled`、HUD 明确文案；
  - 订阅 `onShellCancel`：加载中点停止 ⇒ 台账 `cancelled`、HUD “已停止下载”，迟到的 onLoad 直接 dispose 不挂树，fallback 保留；终态注销订阅；

- `src/ui/Menu.ts`：`.vc-diff` 补 `overflow-wrap:anywhere / word-break:normal / white-space:normal / line-break:strict`，并给 `li` 同样约束；不动卡片布局/颜色/字号。

## 9. 遗留与风险

1. 本轮仍未跑真机核显 FPS 目检；SwiftShader 截图只用于几何/显隐/文案判定，帧时与色彩不作判据。
2. 御桥车心限 10.997 比 R97 的 12.0 收窄约 1m；高架桥面 12.6 仍留净空，但习惯贴边驾驶的体感会变紧。
3. `.vc-diff` 只做 CSS 换行控制，未做真实卡片排版像素回归；外部视觉对 after_cancel 截图已确认三卡无溢出。
4. 仰望取消信号只做到“按钮立即生效 + 迟到 GLB 不挂树 + fallback 保持”，XHR 本身无法中断；慢网下后台仍可能继续下载至结束，但不影响玩家可见状态与加载门。真机慢网断网恢复场景建议后续单独验。
5. 火盆（|x|≈8.9）仍是纯视觉道具，无碰撞；本轮按“每人一小细节”未扩到静态障碍表。
