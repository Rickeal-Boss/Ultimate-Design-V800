# R106 · 撞击顿挫深化（撞击读作真实碰撞，非滑行）

承 R105（`docs/handoff-20261120-0345.md`）。用户四次反馈「撞击硬切（变成滑动）依旧需要改进」。本轮专攻**撞击手感**——这是前几轮唯一未深化的非几何项（几何全量扫已证非漂移城内 0 穿模、漂移/广场已修）。

## 打法说明
本轮原计划双线（撞击手感 + 逐材料分级占位），但：
- **逐材料分级占位 Agent 阵亡（400）后主理人复核，判定其前提不成立，不做**：连墙/角塔飞扶壁墩的多级基座是**向远离路心方向内收**（底级 11.35 最外凸 → 中级 11.6 → 柱身 11.9），**最外凸底级先挡住车，内收级在其后方** ⇒ 单一最外凸 xInner 是正确的，**不存在「内收级空气墙」**（印证 probe-mat 原判「车恒贴地只命中底级」）。剩余 arcade ghost AABB 0.1m（probe 判「驾驶不可感」，收紧到精确 colR 反有 SAT 边界抖动风险）不值得动。
- 故本轮**只交付撞击手感深化**。

## 改法（`src/core/FreeDrive.ts` 撞击区，dev-crash-feel Agent）
目标：撞墙读作一次真实碰撞（接触瞬间清晰可感的速度骤降 + 车身被顶），**不退回 R99 前的单帧速度归零瞬移**。

1. **首帧一次性法向速度扣减**：新增 `WALL_IMPACT_SPEED_KICK_RATIO = 0.4` —— 撞击帧一次性额外扣 `0.4 × impactN` 法向速度，后续仍走 IMPACT_TAU 一阶收敛到分解目标。效果：**正撞首帧速度损失 6.1% → 46.1%**（顿挫可感），但仍非单帧归零（约 12 帧才降到半速，保留 R99 防瞬移成果）。
2. **pitch「点头」冲量**：新增 `WALL_IMPACT_PITCH_KICK_MS = 0.12` / `WALL_IMPACT_PITCH_KICK_MAX = 0.03` —— 撞墙瞬间车头一次性点头（区别于原每帧速率项被覆盖），pitch 峰 0.0312 → 0.0349 rad（到 pitchMaxRad），撞击更可感。
3. **红线零改**：`IMPACT_TAU` / `wallDecay` **均未动**（零红线风险）—— 顿挫来自首帧速度扣减 + pitch 冲量，而非调一阶 τ。
