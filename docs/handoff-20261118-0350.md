## R94-P1 · 中段城内楼群覆盖 —— 已根治

### 定罪（源码级，无需探针）
`castleKit.ts` `makeInnerCity()`：`blocks = floor((zNear − zFar)/blockLen) = floor(920/46) = 20`
（`r28Layout.ts:430` `INNER = { zNear: -358.5 - 7, zFar: -1285.5, faceHalf: 15.5, blockLen: 46 }`）。
块心 `zc = zNear − blockLen/2 − k·blockLen`。

R91 默认 `keep = R91_CITY_KEEP_BLOCKS = 6`，循环 `for (k = 0; k < Math.min(blocks, keep); k++)`
**从 zNear 连续堆 6 块** ⇒ 块心 z =
`−388.5 / −434.5 / −480.5 / −526.5 / −572.5 / −618.5`，**只覆盖 z ∈ [−365.5, −641.5]**。

赛道 barrier 在 z = −1300 ⇒ **z ∈ [−641, −1285] 约 644m 的城内楼群完全为空** = 用户所见
「中段无建筑」。R93 的「非代码回归」结论之所以错，是把城堡桶（`castle-ashlar-z1/z2`）
与**城内街群**混为一谈 —— 城堡桶在场，街群桶整段缺失。

### 修复（`src/render/scene/castleKit.ts`，仅此 1 个 src 文件）
1. 新增纯函数 `cityBlockIndices(blocks, keep): number[]`（可单测，不碰布局常量）：
   - `keep ≤ 1` ⇒ `[0]`（`#r91city=off` 逐位回 R89，**循环仍至少跑一次** ⇒ `castle-pave`
     契约桶在场，禁空循环 / 禁 `setDeepFar` 后 continue）；
   - `keep ≥ blocks` ⇒ `[0..19]`（`#r91city=full` / `#r89city=off` 逐位回 R88）；
   - 否则 `Math.round(i·(blocks−1)/(n−1))` **沿 z 全距均匀分布**。
2. 块循环改走采样索引；**逐块高度递减口径从 `k` 改为分布序号 `i`**
   （`1 − 0.03i`）——否则最远块被削到 `1 − 0.03×19 = 0.43`，明显塌楼。
3. `far = k >= blocks − floor(blocks/3)`、`nearZone`、`hero`、`k % 2` 街面火盆判定**一律不动**
   ⇒ k=15/19 落 `far`（DEEP_FAR 自裁装饰），tri 不升反降。
4. `.qa` 探针 esbuild 锚点行字面**逐字未动**；`r91Keep`/`keep`/`__R91_KEEP_BLOCKS` 探针优先链、
   `Math.min(blocks, keep)` 语义全部保留。

## R94-P3 · 半程爆胎在刹车段永不触发 —— 已根治

### 定罪
`StateMachine.ts` 的 `maybeBlowTire(events)` **只在 `case 'accel'` 内调用**。爆胎线
`TIRE_BLOW_DISTANCE_M = (1300 − 2.7)/2 = 648.65m`。

但玩家**必须在 ~450m 就踩刹车**：满油加速到电子限速的切入里程实测 `cutInM ∈ (650, 675)`
（`tests/tire_blow.test.ts` 断言），200km/h 起刹停需 ~850m，`1300 − 850 = 450`。
⇒ 跨 648.65m 那一帧玩家早已切到 `phase = 'brake'` ⇒ **正常一局爆胎永不触发**。

### 重要时序修正（测试成员实测，推翻主理人原推断）
爆胎**开启**时一路满油门：5200N 拖阻把功率平衡极速压到 **179.76km/h**，永远到不了
199km/h 的 `atLimiter` 门槛 ⇒ 车以 ~188km/h 慢爬，**爆胎确实在 accel 段 648.665m 触发**
（随后 1297.36m 撞主殿 `crashed`）。

⇒ 真正不触发的路径是**玩家早切刹**（在 648.65m 之前踩刹车）：跨线那一帧 `phase` 已是 `brake`
⇒ 旧代码永不触发。这正是用户所见。

### 修复（`src/core/StateMachine.ts`，仅此 1 个 src 文件）
- `case 'accel'` 内删除 `maybeBlowTire` 调用，`extraDragN: this.tireBlown ? TIRE_BLOW_DRAG_N : 0`
  **原样保留在 accel 段**（锁定契约未动）；
- `step()` 末尾（switch 之后、`return events` 之前）统一调用 `this.maybeBlowTire(events)`；
- `maybeBlowTire` 内新增**相位闸门**
  `if (this.phase !== 'accel' && this.phase !== 'brake') return;`
  ⇒ countdown / menu / stopped / crashed 一律不触发（撞主殿与停车后无再触发）。

**刹车段零物理改动**：5200N 拖阻仍只在 accel 段经 `extraDragN` 传入，
刹停距离 / 时间 / 峰值力 / 冗余距离**逐位不变**（新护栏 `toEqual` 机器验证）。
源码级断言锚点未失效：`stepBraking`→`recordSample` 切片仍不含 `extraDragN`，
`case 'accel'`→`case 'brake'` 块仍含该字段，**断言无需改锚点**。
