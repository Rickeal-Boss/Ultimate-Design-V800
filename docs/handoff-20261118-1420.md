### 修复（方案①，最小）

```ts
const FW = 144, FH = 69.97, FD = 7.5;            // x∈[−72,72] z∈[−359,−351.5] y∈[−70,−0.03]
b.ashlar.push(box('ashlar', FW, FH, FD, 0, (−0.03 + −70) / 2, (zFront + −359) / 2));
```

- **±72 裁决**：峡谷槽半宽 GORGE_HALF=70，前脸悬空只 |x|≤70；±72 = 槽宽 + 两侧各 2m 嵌岩（封槽口/岩壁交接缝）。±96 是埋土浪费且会把台基缝从 3cm 撑到 8cm，**不取**。

## 2. P2 分布加密 — 近密远疏（developer 实施）

### 根因
R94 均匀采样 `ks=[0,4,8,11,15,19]` 沿 920m 全距等分 ⇒ 必然 184m 空档；近端也不连续。俯瞰下空档可见（图2 中段空隙）。远端空 = 550m 距离显隐（`updateViewerZ` 流式加载，**设计，不改**）。

### 处方与实现
`cityBlockIndices` 重写为**近密远疏**：`nearCount = max(1, min(n−2, 3))` 钳 3（近端连续 4 块），`far[j] = nearCount + round(j·(blocks−1−nearCount)/max(1, farCount−1))` 均匀铺到 blocks−1；退化分支（n≤1→[0]、n≥blocks→[0..19]）逐位保留。
- `R91_CITY_KEEP_BLOCKS` 6 → **8**；
- **keep=8 ⇒ ks=[0,1,2,3,7,11,15,19]**，块心 z = −388.5 / −434.5 / −480.5 / −526.5 / −710.5 / −894.5 / −1078.5 / −1262.5；
- 近端连续 0,1,2,3（空档 0）、远端覆盖 k=19（barrier 前 37.5m）、最大相邻块心间距 184m（不劣于 R94）；
- 高度递减按分布序号 i（1−0.03i），最远栋 i=7 ⇒ 0.79 ≥ 0.7（不塌，系数 0.03 未动）。
