## 关键侦察结论（沉淀，勿重查）
1. **`V800Adapter.ts:4779` `setPaintShadow` 会对全部 `shell.lampMeshes` 执行 `sm.visible=!interior`** ⇒ 外景态把壳侧设的 `visible=false` 重置回 true。隐藏外部壳语义件**必须从出口数组过滤**（保留内部数组 + 双保险），否则隐藏无效。
2. **`lamp_rear_band` / `lamp_rear_housing` / R49 盖板 / `makeR7RearBandAtlas()` 只在 `ExternalShell.ts:2367` 的 `car==='r7'` 分支**，V800 运行时 0 命中（勿再对 V800 找这两件；`:2366-2472` 是行号归属错误，实际在 ExternalShell.ts）。
3. **尺寸标定一律用各车 manifest.scale**：V800=**4.75**，R7=4.323（混用会整体差 ~10%）。
4. **点阵 mask 羽片半宽必须 ≥ 网格格距**：半宽 0.02 < du 0.05 ⇒ 翼几乎不命中，退化成「竖直拖尾/Y 形」；且 mask v 与 canvas y 反向，需 `v=1-(j+0.5)/rows` 翻转，否则凤凰倒挂。
5. **atlas 半幅比例须贴合目标面**：512×512 方形贴 0.075×0.135 竖灯 ⇒ 1.8× 纵向拉伸；改 512×1024 后残余 1.11×。
6. **R64 护栏 slice 锚点**：`ExternalShell.ts` 既有护栏用 `readFileSync+slice(from,to)`，`:1987` 之前插入声明会改变 slice 边界 ⇒ 整片红；新常量一律后置文件末尾（模块顶层求值、使用点在异步函数体内 ⇒ 无 TDZ）。
7. **视觉模型在缩略拼图上会把真实锯齿判成「软渲染边缘假象」** ⇒ 缩略拼图的视觉结论不能替代逐 mesh 消去法 A/B（本波 `L_white_rearClose.png` + 顶点抖动量化是硬证据）。
8. **R65 210° 轮拱内衬在 on 态也有效**（16 机位扫描无 cognac 皮革透出，此前只在 off 态验过）；R65-G8 机盖机位未落座舱。
