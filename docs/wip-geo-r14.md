# WIP geo-r14 — R14 波「臀线饱满 + 纵向尾灯 + 搁板腔填平」

## 本波目标（用户诉求）
1. **车尾不是掀背是商务 MPV**：后下侧围（后轮后方、保险杠上方）当前向内弧收成「掐腰」，
   必须改成**饱满外凸、近垂直的臀线**，与保险杠平滑包覆，不出现内凹转折。
2. 纵向尾灯：竖长条 + 外框镀铬 + 2~3 道红横条 + 下部琥珀点阵（参考 C3）。
3. R12 遗留：roof-panel 后缘与尾门之间的**深腔「搁板感」**消除。

## 计划
1. 备份 spec → `object-sculpt-spec.json.bak-r14`
2. python 遍历 componentTree 打尾部组件 world bbox，定位「掐腰」组件与 profile 点段
3. 改 profile 点列（不碰 edgeTreatment/deformationStack——生成器不读）
4. 重产工厂：validate → generate
5. `npm run build` + Edge headless 截图（0/30/90/180 + 裸模型尾 3/4）
6. `#uvassert` / `#batchmerge` / `#lightassert` 控制台零 error

### 踩过的坑
- **z 方向语义**：车头 +Z，车尾朝 -Z，**更负 = 更靠后 = 更靠近尾部观察者**。第一版把尾门放到 -2.816，
  结果被车身尾面（-2.820）整体遮住，渲染出来看到的是 body-lower 尾面（同材质，导致读成一块大白板）。
- **父子 z 补偿方向**：tailgate 有 rotY(0)，taillamp 有 rotY(π)；taillamp 的 position.z 不参与自身旋转，
  是直接加在父空间。灯壳 extrude 向局部 +Z → 世界 -Z，所以壳体后端面 = origin - 0.03。
