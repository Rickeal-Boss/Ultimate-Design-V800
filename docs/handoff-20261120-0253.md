# R103 · 阶段二「看不见空隙不挡」— 开放城内块心走廊 + 柱/墩下沉 2D

承接 R102（`docs/handoff-20261120-0155.md`）遗留项：**阶段二 看不见空隙不挡**。
用户铁律：看得见实体贴着挡、看不见空隙不挡。R100 把城内块心段保守钳在 10.0（车缘 11.003），
但柱间/墩间真空隙的最近可见实体是建筑前脸 15.5 ⇒ 约 4.5m 无形空气墙（R102 probe §3.2 A1）。

## 根因（team-lead + probe2-solids / probe2-guards 双探测）
- **架构**：1D「走廊半宽」标量**无法表达「可停在其外侧的周期突出物」**。柱列 11.12 / 飞扶壁墩
  11.35 是周期物，车可合法停在「柱与前脸之间」的空隙（车心到 14.497）；若沿用 1D 窄带钳到
  10.117/10.347，则贴前脸行驶的车一进柱位 z 带就被 `|x|>halfW → x=halfW` **瞬移 4.4m 进路内**（穿模）。
- **殿前大理石带真内缘 = 15.0**（castleKit.ts:3156 `box(0.5,…,−0.25)` ⇒ 世界 |x|∈[15.0,15.5]），
  R102 的 cityFootprints.ts 误取中心 15.25。殿身（|z−块心|≤6.85）须钳 13.997，不能放到 14.497。

## 改法（设计 B：连续墙留 1D，周期物下沉 2D）
`src/core/FreeDrive.ts`：
- `corridorCenterHalfWidth` 块心段（dc≥3）改为**连续墙包络**：`|z−块心|≤6.85`（殿身，
  `TOWER.hallW/2+0.6`）→ **13.997**（殿前大理石带 15.0 − 车半宽 1.003）；其余块心 → **14.497**
  （前脸 15.5 − 1.003）。块角段（dc<3）从角塔大理石基座（连续墙）**13.897** 线性升到 dc=3 包络，
  **全程无 10.0**。新增常量 `CITY_HALL_MARBLE_INNER=15.0` / `CITY_HALL_CAR_CENTER=13.997` /
  `CITY_HALL_ZR_EXTENT=6.85`；import 加 `TOWER`。
- **柱列 11.12 / 连墙墩 11.35 / 角塔墩 11.35（hero 块 k<2）= 周期突出物，从 1D 完全移除**，
  下沉到 step() 的 2D `clampToFootprints`（按车 OBB SAT 真相交防穿模，只收紧不放宽、无瞬移）。
  删除 pillar 1D 常量（ARCADE_PILLAR_*/ARCADE_COL_INNER/ARCADE_PILLAR_PITCH）与 R30_ARCADE import。
- **2D 层保持 `!driftActive` 门控（含位置钳）**：实测漂移态做位置钳会把漂移车钉在前脸、heading
  不收敛 ⇒ β 永不塌缩、rearGrip 不复原（free_drift 恢复段 β 卡 0.27）。漂移中短暂穿越柱/墩窗口
  极短且玩家主动（R102 同款取舍）。

`src/core/cityFootprints.ts`：
- 修正 `HALL_PLINTH_INNER` 15.1→**15.5**、`HALL_MARBLE_INNER` 15.25→**15.0**。
- **角塔飞扶壁墩（⑥b）从 `void` 启用为真实 2D 占位**，仅 hero 块（k<2，CITY_BLOCK_Z[0]/[1]）
  每块 2 座（z 同角塔中心 `zc±(half−0.5)`，z 半宽 1.05，内缘 11.35）⇒ `buttressBase` 总数 20→**24**
  （20 连墙墩 + 4 角塔墩）。非 hero 块渲染端不建此外墩 ⇒ 不占位（避免假空气墙）。循环改带索引 k。

## 测试（重钉 6 文件 + 新增 1 文件 + 修 free_drift）
- 重钉块心 10.0/10.117/11.003 → 设计 B 新值：`r100_boundary_precision` / `r98_car_edge_bounds` /
  `r99_corner_bounds` / `r102_footprint_bounds`。
- `r102_scrub_contact_hysteresis` / `r102_column_gap`：柱位 0.117 跳变 premise 已消失，pivot 到
  设计 B 真实场景（跨段放宽跳变 latch 不闪断；块内 13.997↔14.497 跳变 scrub 不误清；柱由 2D 防）。
- **新增 `r102_phase2_open_block.test.ts`**：钉块心开放（1D≥13.897 永不回 10.0）、柱 2D 防穿模、
  殿身 13.997、角塔墩 hero-only、漂移豁免。
- `free_drift.test.ts`：恢复段改**零油门零转向**诚实恢复（旧「继续给油」在开放走廊让 heading 永久
  偏向前脸、绕圈不收敛、β 卡 0.27）；β 半衰阈值 2.05→**2.55s**（走廊放宽后漂移车多走 ~4.5m 才撞
  前脸墙，实测 β 半衰 2.525s、2.77s 恢复）；车缘护栏从「柱内缘 11.12」改为「前脸线 15.5」。
