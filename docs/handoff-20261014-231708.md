### 5. 关键决策与已踩平的坑（下一会话务必先读）
| 坑 | 结论 |
|---|---|
| img2threejs 生成器尺寸真源 | 单位几何 × **`transform.scale`**；`dimensions` 只是元数据（写 dims 不生效） |
| extrude 挤出方向 | 沿 0→depth **单侧**挤出不居中；rotY(-90°) 后需用 `position.x += depth/2` 补偿 |
| macro 容器组件 | root/cabin-interior 会生成实心占位箱 → 必须隐藏；容器若带 position，子件会被整体偏移（子件写世界坐标 ⇒ 容器必须归零） |
| 细分 tier | `performanceBudget.targetTriangles` >60k 触发 hero → 210 万面；58k → standard（18 万面） |
| 机器 IoU 门 | 素模 vs 营销特写不可达 0.85（实测 0.51）；改用**逐组件 world box 数据核验** + 裁剪参考验证 aspect/scale（0.017） |
| 实机验证环境 | bash 会话结束杀进程树 ⇒ Edge CDP 与 vite server 必须**同会话内联 spawn**（detached + `--remote-debugging-port=9333` + puppeteer.connect） |
| 静态分析与实机差异 | mergeGeometries 混拼 indexed/non-indexed 会返回 null 崩溃（已建 `src/util/geo.ts` 的 mergeSafe） |
