# R104 · 逐材料边界修复 + 撞击手感改进

承 R103（`docs/handoff-20261120-0253.md`）。用户反馈：「空气墙/穿模、撞击硬切（变成滑动）依旧需要改进，需要**细致每个建筑底部材料的边界**」。两线并行。

## 线 A · 建筑底部逐材料边界（`src/core/cityFootprints.ts`）
probe（`verify/r104_probe_mat.md` 思路 + 主理人查 castleKit/castleDetail 真源核实）定位两处真源派生错误：

### P1 前排塔基穿模 0.7m（40 处，普通驾驶即中）
- 真源 castleKit.ts:3254 `put(box('ashlar', 9.4, 1.2, 9.4, depth/2, 0.6, tzC))` —— 塔基 box 宽 9.4、中心局部 x=depth/2=4 ⇒ 局部 x∈[−0.7, 8.7] ⇒ 世界内缘 = faceHalf − 0.7 = **14.8**。
- 旧 `FRONT_TOWER_BASE_INNER = INNER.faceHalf`(15.5) 比真内缘靠外 0.7 ⇒ 车穿进塔基 0.7m。
- 修：`FRONT_TOWER_BASE_INNER = INNER.faceHalf − 0.7`，0.7 = boxW/2 − depth/2 = 9.4/2 − 8/2 真源派生；澄清 boxW(9.4) vs depth(8) 命名。

### A1 拱廊柱 AABB z 向过宽 ⇒ 4.38m 空气墙（每 8.8m 一处）
- 真源 castleDetail.ts:1396 `colR=0.3`、:1408 `pierColumn(colR*2,…)` ⇒ 柱实际 z 半宽 = colR = **0.3**。
- 旧 `colAabbHalf = colR + 0.6` = 0.9 比实际靠外 0.6/侧 ⇒ 柱位 z 带车被 2D 挡在离柱 0.6m 外。
- 修：`colAabbHalf = colR + 0.1` = **0.4**（0.1 微小稳定余量防 SAT 边界抖动）。xInner 11.12 不变。

其余实体（角塔基座 14.9 / 殿台基 15.5 / 大理石带 15.0 / 连墙墩 11.35 / 角塔墩 11.35）保持不变。

## 线 B · 撞击手感「硬切变滑动」（`src/core/FreeDrive.ts` 撞击区）
probe（`verify/r104_probe_impact.md`）查明：速度与 heading 共用 τ=0.12s 平行收敛 ⇒ 速度目标随仍递减的 impactN 漂移（正撞 20m/s 只掉 43% 散到 0.2s、首帧 −6.9%）；横摆注入是速率项、每帧被 wallImpact damp 覆盖 ⇒「被顶一下」不可见 ⇒ 都读作"顺墙滑"。

改法（组合 ③+④，**全部避开锁定红线**，未改任何现有常量数值）：
- **③ 分离 heading τ**：新增 `WALL_IMPACT_HEADING_TAU=0.22`（>IMPACT_TAU），`impactHeadingStep` 的 τ 从 IMPACT_TAU 换成它。heading 收敛放慢 ⇒ 车头多指向墙 ⇒ fn 停留更大 ⇒ 撞后几帧持续刮擦减速（顿挫），速度一阶防硬切成果保留（s.speed 仍 damp 1/IMPACT_TAU）。
- **④ 集成 yaw 冲量**：新增 `WALL_IMPACT_KICK_MS=0.15` / `WALL_IMPACT_KICK_MAX=1.2`。撞墙帧一次性记 wallKick（latch 防重复），在 KICK_MS 内分摊加到 yawRate，放完即止（不再被每帧覆盖）。hall 撞击也记 wallKick（不触发 heading 收敛，纯视觉顶一下）。新增 private 状态 + reset() 归零。

手感前后（正撞 v0=20）：0.2s 速度 旧 12.53 → 新 9.24（多减速）；yaw 峰 0.0667（旧 2.4×）。**保留 R99 防单帧硬切成果**。
