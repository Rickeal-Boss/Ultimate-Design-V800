## 全量扫方法（主理人，`verify/r105_probe_sweep.md` 思路）

- **非漂移城内：0 穿模**（SAT `clampToFootprints` 保证；单一 xInner 取最外凸级对非漂移是安全保守的 ⇒ **多级台阶重构非当前根因**，不做）。

## 修 A · 漂移穿模根治（`src/core/FreeDrive.ts` step() 2D 区，dev-drift2d Agent）
去掉 2D 层外层 `!driftActive` 门控 ⇒ 漂移态**也做位置钳**（`s.x=fp.x`），堵死漂移穿模 3.5~5.6m。
R103 关掉它的真因是「位置钳 + 撞击/速度/heading 注入」让 β 永不塌缩（非位置钳本身）。故按 `driftActive` 分流：
- 非漂移：原 2D 行为逐位不变（位置钳 + 撞击/heading/scrub 链路）。
- 漂移：只做**位置钳 + 朝向贴墙收敛 + β/动态横摆回收**，**不注入 impactN / 不 damp speed / 不加 scrub / 不触发 wallImpact·wallKick**（这些是 β 半衰回归元凶）。
- 新常量（独立于 IMPACT_*/灵魂表，**未改任何既有常量数值**）：`WALL_IMPACT_DRIFT_HEADING_TAU=0.30`（漂移 2D 接触朝向收敛，比 WALL_IMPACT_HEADING_TAU 0.22 更缓）、`WALL_IMPACT_DRIFT_BETA_RATE=9.0`（贴 2D 占位期间 β/横摆回收速率，补「2D 提前拦下 ⇒ 车到不了 1D 前脸墙 ⇒ 失去撞墙塌 β」的缺口）。
- **β 塌缩保住**（free_drift）：β 半衰 2.225→2.442s（阈值 2.55）、recovery 2.350→2.683s（阈值 3.0），free_drift 9/9 绿；漂移恢复段 `clampToFootprints` hit 穿模帧 **187→0**。

## 修 B · 主殿前排飞扶壁占位（`src/core/cityFootprints.ts` + FreeDrive 2D 门控，主理人）
全量扫 + 真源核实（castleKit.ts:2731/2742 + castleDetail.ts:337/342/344）：主殿正脸前排 3 对递减飞扶壁经 `pour(...rotateY(-π/2).translate(side*wx,0,zFront))`（**直接放置不走 put/faceHalf**，zFront=-1300）落到广场 z≈**-1294.3**，比最南块 k9（zmin=plazaZ=-1285.5）还南 ⇒ 双重缺口：①在 2D 激活带 [plazaZ,gateBackZ] 之外；②buildCityFootprints 无此条目 ⇒ 广场 1D 车缘≈16.5 直穿内墩基座（内缘 10.425）最多 ~3m。
- 坐标映射（rotateY(-π/2)：世界 x = side·wx − z_local，世界 z = zFront + x_local）：内墩对 `pierZs=±pairGap/2` ⇒ 世界 |x| = wx − pairGap/2 = 11.9；基座 `box(pierW+1.1,0.5,depth+1.1,…)` ⇒ 世界 x 半宽 (depth+1.1)/2=1.25；hi-detail 大脚再外扩 0.3 ⇒ 内缘 **10.425**；世界 z = zFront + (reach−pierW/2) = -1294.3，z 半宽 (pierW+1.1)/2=1.85。
- `buildCityFootprints()` 块循环外 push 1 条 plaza 内墩 footprint（xInner 10.425，双侧镜像单条）；外墩 wx≥21.5 内缘>16.5 车不可达 ⇒ 不占位（免假空气墙）。
- **FreeDrive 2D 门控下界 plazaZ → zMin**（`nz >= BOUNDS.zMin`）：让广场 footprint 真正被 consult；该域内仅此一条 footprint ⇒ 不引入别处假钳位。
