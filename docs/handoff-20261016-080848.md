## 一、本波目标与结论

**目标**：深度优化车辆模型精度。

**结论**：精度层的根因不是"细分不够"，而是 **46 个 micro 组件写死在 spec 里、生成器从未发射**。

- `componentTree` = macro 10 + meso 85 + **micro 46** = 141
- 生成器 `PASS_LEVELS`（`forge/stage3_build/generate_threejs_factory.py:59`）规定
  `structural-pass` 只发射 `{macro, meso}`，**micro 要 `form-refinement` 才解锁**
- 流水线此前卡在 `structural-pass`，所以精度层一直没落地

→ 解法不是调 tessellation，而是**推进 pass 链**。同时 micro 全量发射 = +46 DC，
而整帧 DC 已贴红线 150，所以必须先腾 DC 预算。两线并行、文件零重叠：

## 三、修复的缺陷

### 结构缺陷（B 线，spec 回写 → 生成器重产）
1. **roof-rails 落在地面** y[-0.06, 0.06]。根因：attachment 坐标写成 `roof-panel` 局部系，
   而生成器单圆柱分支落在 `root` 系。改为零长度 attachment 走 `tubePath` 闭环分支 + 八角闭环
   （原 90° 尖角在 CatmullRom 下先 z 后 x 过冲，两轮迭代收敛）。终态 y[1.710, 1.754] 贴车顶。
2. **lidar-wedge 悬浮车顶上方 0.136m** 且越过车顶前缘（z 中心 1.28 > 前缘 0.98）。
   transform 改 [0, 1.75, 0.8]，终态 y[1.706, 1.794]、z[0.638, 0.962] 在前缘内。

### 既存 bug（A 线）
3. **悬浮轮标一直没朝向相机**。`V800Adapter.update()` 把相机的**世界**四元数直接赋给 cap 的
   **局部** `quaternion`，而 `body` 上有 `rotation.y = π`，父链旋转叠加后实际朝向差 **180°**。
   盘面 20 开窗接近对称所以长期没暴露。
   修法 `local = parentWorldQ⁻¹ × cameraWorldQ`；实测 4 机位 180° → 0°、绕车 72 方位 worst
   **2.415e-6°**、body 俯仰（刹车点头）worst **0.000e+0°**、轮标世界位置 0 位移。

### spec 数据缺陷（主理人修复，strict-quality 复验 PASS）
4. `taillamp-l/r` 的 `colorMaterialRecipe.dominantAlbedo = rgba(232,233,236,1.0)`（近白）
   与材质 `lamp-red` 的 `#B51F2C`（红）不一致 → 已对齐为 `rgba(181,31,44,1.0)` 并加 note
   说明原值是"高自发光时的外观采样，不是 albedo"。
5. `performanceBudget.maxDrawCalls = 42` 从 95 mesh 时代起就物理不可达（当时 89 visible），
   不是本轮回归 → 改为 **60** 并新增 `drawCallScope` 口径说明。
6. `blockout` 的 `mapStrippedRender` 嵌套在 `visualEvidence` 内导致 `append_review.py` 的
   `review_completes_pass` 始终认为 blockout 未完成 → 已提升到顶层（只挪位置，值未改）。

## 六、给下一波的操作纪律

- **改模型先改 spec**，再由 `generate_threejs_factory.py` 产出工厂；工厂产物不手改。
- **工厂重产后必须重跑合批数字**（mesh / DC / 面数 / world bbox）。本波「提速」两次读到
  面数不同（22,816 → 22,048 → 38,640）就是因为「搭景」在反复重产工厂。
- **turntable 必须用 stripped 模式**（白模 + 纯黑底）。暗底暗车会导致
  `segmentationReliable=false`，本波首次 turntable FAIL 就是这个原因。
- **reference-based Tier1 跑不了**：外部参考图 `huawei-zunjie-v800-design-black-2x.jpg`
  已按权利人合规要求移除，磁盘不存在。判据固化为「逐组件 world box 数据级核验 +
  多机位无退化 + part coverage」。不要试图恢复该参考图。
- **多代理并行**：派发前给每个成员**正向文件白名单**，并禁一切 git 写命令
  （checkout / restore / stash / reset / clean / add / commit / apply / push）。
