## 二、病根定性（外部诊断报告结论，本波已据以动刀）

外部审查报告《致主理人_车内视角穿帮结构性结论与处置建议》定量定罪（用户 11-13 提供，原文件在用户桌面 `<DESKTOP>/致主理人_车内视角穿帮结构性结论与处置建议.md`）：

1. **状态层（雪崩放大器）**：车内/外景显隐分散在 **5-6 套系统**（`Game.syncInteriorOcclusion` / `setPaintShadow` / `setExteriorHidden` / `setPokeHidden` / `cabinOccluderMats` / R7 `applyRearViewOverrides`），交叉写同一属性（`mesh.visible` 被 5 套写、`material.visible` 被 3 套写），且全是「差量登记 + 条件恢复」，**无每帧无条件重算、无仲裁者** ⇒ 62.6% mesh 可见性由「写入顺序」决定 ⇒ 全车贴图失效 / 车身消失 / 座椅时有时无 / 切机位雪崩。
2. **几何层（病根）**：V800 顶棚 6 层薄板堆叠（y 差 6–93mm，2 层带贴图），多块**高于壳顶 roofGlassY≈1.647** ⇒ 永久穿顶 ⇒ roof/front34/俯视机位「白色大板」。R7 侧无此病（顶棚本就是单块 conforming-shell）。
3. **验收层（复发原因）**：424 条护栏 0 条读渲染像素，历史每轮只在单机位验收 ⇒ 换机位复发。
4. **自锁循环**：补丁 → 合批整批波及 → 新机位新穿帮 → 再加白名单/特例/回滚开关 → 状态更碎。13 组整改 100% 打在可见性开关层，0 次动几何。

**报告给出裁决选项**：A1 立项削几何（推荐）/ A2 仅止血 / A3 维持。**本波主理人裁决 = 采纳 A1，分波推进：W1 状态表止血 → W2 削几何治本。**
