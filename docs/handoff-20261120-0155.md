## 1. 探测结论（verify/r102_probe_*.md）
- **scrub 失效**（scrub 报告 Agent 阵亡，主理人依 R101 深度审查报告 + bounds/stuck 交叉定因）：R101 wall scrub 接触判定 `|x| ≥ corridorCenterHalfWidth(z) − 0.05`，但该函数随 z 段间跳变（桥 10.997→隧道 8.997→块心 10.0→柱位 10.117→空档角塔 13.897）。车贴上一段墙 x 不变而 halfWnow 变大 ⇒ 闪断误清零；−Z 主诉方向 2.842s 后永久失效。另有柱位邻域 ε=0.05 < R100 跳变 0.117 的 0.067 缺口。
- **穿模/卡台阶**（probe-bounds）：边界是「1D 车心点钳位」，车长 5.495m（半长 2.7475）/车宽 2.006（半宽 1.003）bbox 从未检查、heading 不进钳位。斜插 θ=30° 车角 dx=2.243 ⇒ 块角基座内缘 14.9 处嵌 1.24m、柱位 11.12 处嵌 1.12m；车尾 bbox 落 zc±2.75 合法待钳位线外与 6.2m 深台阶相交 = 卡台阶缝隙。台阶 2D 占位清单已查实（角塔基座 14.9/前排塔基 14.8/柱 11.12/飞扶壁墩 11.35/前脸 15.5/桥栏 11.88）。
- **边界卡死**（probe-stuck）：wallScrubN 以 Math.max 记峰、贴墙永不衰减，scrub 封顶 12 > 油门净加速 6.11 > 倒车 2.08 ⇒ 单帧钳回 0；yawRateFor 因子 ∝|v|→0 ⇒ 无法转向脱困。
- **渲染距离**（主理人自探，render Agent 阵亡）：远景环 R27/R28 刻意低模（1600/1200 环、~1040 tri、MeshLambert+顶点色+混雾 0.15→0.55、rockCliff #665a4d），扁平=低分段+强雾洗+纯顶点色，非硬裁剪。有明度红线白石:岩石≈1.6:1。

## 2. 本轮改动
- **`src/core/cityFootprints.ts`（新增）**：纯数值 2D 占位模块（无 three/DOM，FreeDrive 无 DOM 单测可 import）。`buildCityFootprints` 由真源 INNER/R30_ARCADE/R97_CITY_BUTTRESS/VEHICLE/CITY_BLOCK_Z 派生 10 keep 块 × 6 类地面实体 AABB；`clampToFootprints(x,z,heading)` 用 SAT 把车 OBB 4 角点 x 伸展 dx(θ)=半长|sinθ|+半宽|cosθ| 收紧到 `|x| ≤ xInner − dx(θ)`，只收紧不放宽。
- **`src/core/FreeDrive.ts`**：
  - ②D 收紧插入 step() resolveBounds 之后，城内域门控 `z∈[plazaZ,gateBackZ]` 且 **`!driftActive`**（与 R101 scrub 同源：漂移态轮胎摩擦圆已主导，再钳 x/注撞击属双重惩罚，实测拖慢 β 塌缩 2.05→2.57s）。
  - scrub 离墙滞后：`WALL_SCRUB_RELEASE_EPS=1.2` 双阈值 + `WALL_SCRUB_LATCH_FAR_FRAMES=60` 持续远离闸门，堵死段间跳变误清零。
  - 低速脱困：`WALL_SCRUB_RELEASE_MS=1.5`，贴墙+低速+玩家主动操作时给 0.35·maxYawRate 最小转向权限让车头转离墙。
- **`src/render/scene/Terrain.ts`**：远景环加层次（分段/顶点色细节/空气透视），守明度红线、确定性噪声（makeLcg）、tri 预算内。
- **新增测试**：`r102_scrub_contact_hysteresis` / `r102_column_gap` / `r102_footprint_bounds` / `r102_stuck_escape` / `r102_terrain_ring`。

## 3. 主理人兜底修复的 3 处集成 bug（并行 Agent 各改一处的代价）
1. **−X 镜像碰撞漏洞**：占位清单以 |x| 存储（正值），`obbOverlapsAabb` 未按车所在侧镜像占位盒中心 ⇒ −X 半城车永远对不上 +X 占位盒、SAT 判不相交 ⇒ 左侧 2D 收紧整段失效。修：按 `cx<0` 把占位盒中心 x 取负再判交。
2. **测试 z 算错**：footprint 测试假设飞扶壁墩在块角，实测墩在连墙段中点 lz=zc−19.6=−408.125（比块角内缩 3.3m）⇒ SAT 正确判不交。修：4 例改用真实墩位 z。
3. **漂移回归**：2D 收紧在漂移恢复段触发 spurious wall impact（实测 5 次撞墙、β 半衰 2.05→2.57s）⇒ 违反 R101 漂移豁免意图。修：城内 2D 收紧整体 `!driftActive` 门控。
