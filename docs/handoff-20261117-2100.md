### ② 半程爆胎稳行玩法（方案 A：加速段拖阻，刹车段零影响）
- **姿态平稳是结构性保证**：主线严格 1D 纵向物理——车轮是纯 `THREE.Object3D` 枢轴（无 cannon 轮体），帧循环只写 `body.rotation.x`，横向/俯仰姿态角从不参与；不碰 crash 翻滚链。视频素材（用户提供的爆胎 mp4，视觉技能分析）亦证车身水平、无侧倾、车速不骤降。
- **半程判据**：`TIRE_BLOW_DISTANCE_M = (TRACK.barrierDistance 1300 − START_OFFSET_M 2.7)/2 = 648.65m`（冻结常量派生，不写魔法数），实测该点车速约 198km/h。
- **物理**：`VehicleInput.extraDragN?` 新增（Vehicle.ts），`accel = (fMotor − drag − roll − extraDrag)/MASS`；StateMachine `case 'accel'` 在爆胎后传 `extraDragN: 5200`（5200N/3300kg≈0.16g，功率平衡极速 179.8km/h）。**刹车段绝不叠加**——否则爆胎反而刹得更短（182→166m）、冗余距离从 433m 砍到 290m，玩法反转。
- **事件**：`GameEvent` 加 `{type:'tire_blow', distance, speedKmh}`，`maybeBlowTire()` 在 accel 段跨线触发一次；Game `handleEvent` 加 `tire_blow` 分支——`snapTire(0)` 左前轮独立 deform 组压扁（scale.y=0.55, rotation.z 微歪）+ HUD 提示 + warn 音 + 振动，**绝不切机位/不碰 body.rotation**。
- **开关**：`isTireBlowEnabled()` 运行时求值——浏览器默认开、`#r92tire=off` 关；**vitest/Node 无 window 恒关**（否则爆胎拖阻压速到 179.8km/h 回不到 199km/h 门槛，既有「限速自动切入」数值锚全废）。这保证 v800/r7 两车物理逐位不变。
- **护栏** `tests/tire_blow.test.ts`（13 断言）：含「同一初速下爆胎/未爆胎的刹停距离/时间/采样/冗余距离逐位相同」核心契约 + 源码级「stepBraking 不含 extraDragN」+ 无横向姿态字段。
