## 一、先回答「这轮在修什么」

审查人报告 §0 一句话结论：**R82 修对了三件事（R7 横贯黑板、C2 双侧锯齿、顶棚补片几何都建出来了），但头号改动「车内看穿根治」在默认路径下 0 像素生效** —— 补片挂进程序化树，被状态表 pass1 的材质级 `kept` 判定整批关掉。

这不是「修补无效」，是**和 R57/R58/R65/R66 完全同源的第 5 次复发**：新增件只登记了 **mesh 级白名单**（`R44_KEEP_MESH_NAMES`），没登记**材质级 kept**（`material.userData.sculptMaterial.id ∈ R44_INTERIOR_MATERIAL_IDS`）。审查人用强制 `material.visible=true` 证明补片一旦放行，主驾抬头看穿面积 397,447 → 130,521（**−67%**）—— 几何对、处方对、只差一行放行。

本波把这一行补上，并把「新增 mesh 必须同时登记两层白名单」固化成装配期自动断言，防第 6 次。

### 编排纪要（子 Agent 429 阵亡，主理人兜底）

- 7 探测 Agent 派发，**4 个 429 阵亡**（probe-roofpatch / steering / wheelhub / guard），关键路径分析主理人亲自接手（读源码 + 目检审查拼图 sheet82-1~5）。

4. **P1-5 R7 尾灯**：正尾/尾 3/4，中央灰黑方块 + 红带是否消失。**米色翼片锯齿预期仍在**（GLB 资产缺陷，转资产线）。`#r83r7tailcenter=off` 对比可证。
