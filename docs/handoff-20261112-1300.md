- **`setExteriorHidden` 对 `r44External===true` 直接 return**（`V800Adapter.ts:4901-4943`）⇒ 拿它隐 C2 件必然「隐了个本就跳过的对象」，逐位相同假阴性。消去法一律自设材质级 `visible=false`；`#assembled` 合批后按对象隐藏会被吞并，材质级是唯一可靠层。
- **写盘竞态纪律**：Phase 3 开工前不读 `tailLampC2.ts` / `tests/r67_tail_c2.test.ts`；源码逐字复核推迟到 mtime 与开发收尾时间对时之后。7 个 off 钩子的源码命中核对同理。
