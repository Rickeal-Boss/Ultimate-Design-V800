## 0. 用户诉求与关键澄清（最高优先级）

- R99 反馈："补墙可以了；空气墙/穿模、撞击硬切依旧需要改进"，附 37.5s 录屏。
- **关键澄清（覆盖前序推断）**："车能开上白色人行道/广场或者开出边界都没问题，是要解决**挡车边界的精度问题**"——即不把车困在路面（否决"补可见街沿""收车心限到 6.397"等回避方案），只让挡车边界**精确贴合可见实体**：看得见实体处贴着实体挡，看不见空隙处不挡。
- 录屏视觉初判的三现象（穿模/硬切/空气墙）经主理人逐帧目检**大部分是误读**：18s/24s 帧"车被白柱切成两半"=玩家切漂移低机位、近景柱遮挡镜头（柱连贯/轮着地/透视正常）；20s/30s 帧"车瞬间出现消失"=玩家在顶部按钮栏主动切自由/漂移/追尾视角（有鼠标光标、按钮高亮）；30s"相机穿墙"=右侧灰矮墙只到车腰的可见实体遮挡。按项目铁律「视觉模型分歧不可采信」，以主理人目检 + 代码探针为准。

## 1. 三项落地改动

### P1 挡车边界精度贴可见实体（FreeDrive.ts `corridorCenterHalfWidth` 一个函数体）
- **柱列周期贴实体**：块区 dc≥3 段不再恒定 10.0，按柱 z 周期 f(z)：柱位邻域（|z−z_pillar|≤1.303，柱位 zc±4.4/±13.2、pitch 8.8）车心限 = 柱内缘 11.12 − 车半宽 1.003 = **10.117**（车缘贴柱，比现状松 0.117m）；柱间维持 10.0——**不放宽到 14.497**：审查团实测飞扶壁墩内缘 11.125/11.35 < 14.497，放宽必撞墩，柱间可穿在当前几何下无净空，维持窄带是正确产品决策（如实声明）。
- **空档角塔带贴实体**：空档分支若 z 落在任一街区块边界外侧 0~2.6m（角塔基座伸进空档覆盖带），车心限 13.897（车缘 14.9 贴基座），其余空档 14.497；外端 0.4m 线性过渡消抖。
- 真源全 import 派生（R30_ARCADE / INNER / VEHICLE / R97_CITY_BUTTRESS），禁写死 10.117/11.12/8.8/1.303/2.6；`corridorHalfWidth`/`BOUNDS` 逐位不动（CameraRig 依赖）。
- 跨层依赖 `core/FreeDrive → render/castleKit` 的 R30_ARCADE 只读 import：已验证无循环、无模块副作用。
- free_drift 恢复时间阈值随新边界重标定 2→2.05s（柱位贴柱后恢复段 z≈−375.9 少一次 side 钳位、beta 晚 4 帧 2.025s，物理正确），并补"柱位段车缘 ≤ 柱内缘 11.12"防穿模断言，阈值放宽不掩盖真回归。

### P2 撞击 hall 分支瞬态复用（FreeDrive.ts hall 分支 + step 写回）
- 定罪：R99 已把 side/end 改一阶，但 hall（撞主殿）仍 `speed:0` 一帧硬停 + pitch target 跳变 + 漂移态瞬时清零。
- 改法：hall 分支带出 `impactN=|v|`（**不设 targetHeading、speed 仍 0** 守"一次性彻底停"契约），step 注入 wallImpact 包络让 beta/yawDyn 一阶收敛、yawRate/roll 出短暂瞬态（"被顶一下"）；新增 hallCd=1.6s 防二次撞击抖动；`s.accel=0` 改一阶收敛。
- 审查团四条打回触发全满足：不写 body.rotation / 不接 crashWorld / 不改 zMin·hallBounce·barrierDistance / 无二次 hall 抖动。challenge crash 慢动作通路一行不碰。R99 旧测试 `hall.impactN===undefined` 适配为 `===20`。

### P3 瞬态超幅硬 clamp（FreeDrive.ts 瞬态注入处）
- Phase3 审查观察项：注入 `s.roll += gain·wallImpact·(dt/tau)` 在下游 `clamp(rollTarget)` 之前，灵魂上限只约束 target 不约束 state；全油门 200km/h 撞主殿 roll 峰 0.109rad（超 3.5° 上限 79%）、R99 side 高速撞墙同 0.1085（既有包络固有特性）。
- 收口：注入后立即 `s.roll=clamp(±FREE.rollMaxRad)` / `s.yawRate=clamp(±FREE.maxYawRate)`，瞬态体感保留、幅度收进真车合理包络。高速 55m/s side/hall roll 峰 0.108→0.059（合规），低速 25m/s 逐位不变（零回归），瞬态仍持续 177 帧。测试含"移除 clamp 后 3 例立刻红"的守卫有效性实证。

## 3. 遗留 / 风险（如实登记）
1. 柱间不可穿：飞扶壁墩内缘 11.125/11.35 与柱内缘 11.12 前后脚，净空仅 0.117m，当前几何下"柱间开穿"无物理空间；如未来产品要求可穿，须同步重标 reach 并重布火盆/基座带（超小细节，另立专题）。
2. 角塔基座伸进空档 2.6m 的 0.6m 嵌入本轮已修（空档角塔带收 13.897），但 corner 2.6m 外端 0.4m 过渡带内的连续性依赖单步位移 <0.463m 假设，已由 r100_boundary_precision 逐点钉住。
3. hall 持续按油门会从弹开点重新加速再撞（hallCd=1.6s 去抖、25s 约 11 次）——R99 既有"speed:0 + 弹 0.8m"契约的固有行为，非二次抖动（间隔≥1.6s、终态稳定），列目检观察点。
4. 真机核显 FPS / #perfhud 整帧 DC 未跑（SwiftShader 截图仅判几何/文案）；tester 建议发布前补核显实测（含/不含 transmission 分别记录）。
5. 录屏中车开上白色人行道/广场按用户口径是允许行为，本轮零改动。
