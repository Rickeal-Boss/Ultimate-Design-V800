## 三、⚠️ 磁盘危机与恢复（下波必读）

- **现象**：截图时 C 盘降到 **0 可用（ENOSPC）**，所有删除通道（safe-delete wrapper / trash / `find -delete` / `Remove-Item` / .NET Delete）都被 ENOSPC 拦截，`npm ci` 也失败（wrapper 走 trash 满盘写不下）。
- **根因**：本轮反复起停 dev server 留下**孤儿 node/esbuild 进程**（锁 rollup `.node` / esbuild.exe）+ `.qa` 历史截图累积 **3GB**。
- **恢复手法（实测有效）**：
  1. **杀孤儿 node/esbuild 进程**（dev server 残留锁文件）⇒ 释放大头，C 盘 0→4.1GB。`Get-Process node,esbuild | Stop-Process -Force`（**保留 WorkBuddy 本体 node**，别全杀）。
  2. `.NET [System.IO.Directory]::Delete(path, $true)` 直调不经 wrapper（但 blocklist/锁定 `.node` 仍 Access denied）。
  3. 同卷**重命名**挪走锁定目录（`@rollup`→`@rollup_locked_r70`，绕过锁），再删。
  4. `npm ci` 重建 node_modules（61 packages）。
- **教训**：①C 盘临界时**先杀孤儿 dev server 进程**（比删文件释放更快）；②别一次性删 `typescript`/`three`（build 需，删了要 `npm ci` 重建）；③反复起停 dev server 必留孤儿进程锁文件。
