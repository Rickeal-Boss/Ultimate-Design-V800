## 五、双车玩法（R15-4）

`src/config/vehicles.ts`：档位只描述差异，热参数/制动力学两车共用。

| 档位 | brakeBreakable | brakeTempGainScale | 结局 |
|---|---|---|---|
| 尊界V800 | true | 1 | 满踩 1.77 s 断裂 → 冗余 25% 接管判负 |
| 智界R7 | false | **50** | 踏板钳在 1612 N 永不断裂；任何机械制动 ~0.09 s 进红区 → 2 s 断力 |

**R7 实测（`tests/vehicles.test.ts`）**：100 km/h 切入、b=0.25 轻踩 → **12.82 s / 191 m 停住，热保护介入 5 次，score 782**。
50× 升温使摩擦制动变成「只能点一下」的稀缺资源，主力减速必须靠电回收（b≤0.25 段机械项小、且红区期间回收保留）。
若拖到限速再切刹车 → 撞障，属设计后果，报用户拍板是否配平。

## 七、R15b 补丁：座舱遮挡定性收口（2026-10-19）

**消去法定罪**（新增 `#hidemat=<ids>` QA 钩子，按材质隐藏 + 截图对照，`verify/r15b/`）：

| 用例 | 结果 |
|---|---|
| `cab_base` | 画面左右两块绗缝大板占屏 ~45%，路面只剩细缝 |
| `cab_no_leather-warm` | **视野干净**：三联屏 UI（88 / 10:36）、方向盘弧、路面全部露出 |
| `cab_no_leather-dark` / `cab_no_leather-ivory` | 遮挡物仍在 → 与仪表台/门板无关 |

结论：遮挡物 = **第一排座椅（坐垫+靠背+头枕，材质 `leather-warm`）**，不是仪表台、不是中控台、
也不是 R14 假设的「中央隔板实体块」。座舱纵向布局被压缩（座椅世界 z≈−0.9、仪表台 −1.55），
眼点无论落在 −0.58 / −0.85 / −1.12 / −1.36 都会撞上某一排座椅靠背（`#eye=` 纵深扫描 4 点，`verify/r15c/`）。

**处置**（座舱机位通行做法，不改几何）：
- `CABIN_OCCLUDER_IDS`（V800）/ `R7_CABIN_OCCLUDERS`（R7）：整组第一排座椅**排除静态合批**，
  保持组件可寻址；`Game` 在 cabin 系机位期间隐藏，车外机位原样保留。
- 代价：多 ~4 draw call（车模 DC 73 → 约 77，仍在预算内）。
- 新增 QA 钩子：`#hidemat=<id1,id2>`（按材质隐藏，合批后依然有效）与 `#eye=x,y,z[,tx,ty,tz]`（座舱眼点标定）。

**结果**（`verify/r15e/v800_cabin.png`）：路面从画面 1/3 处以上全可见，三联屏完整露出，
方向盘弧在画面下沿——「正前方被屏幕/大板压住」这个问题到此收口。
