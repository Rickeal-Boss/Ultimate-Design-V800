# 极限刹车挑战 · 尊界V800

Vite + TypeScript + three.js + cannon-es 构建的程序化三维刹车挑战小游戏。
全部模型、贴图、音效均在本项目内程序化生成（几何体拼装 / Canvas 贴图 / WebAudio 合成），不使用任何外部图片、模型、音频或字体文件。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建（tsc --noEmit && vite build）
npm run preview  # 预览构建产物
```
