# 极限刹车挑战 · 尊界V800

Vite + TypeScript + three.js + cannon-es 构建的程序化三维刹车挑战小游戏。
全部模型、贴图、音效均在本项目内程序化生成（几何体拼装 / Canvas 贴图 / WebAudio 合成）。

**资产口径（精确表述）**：运行时产物（`dist/`）**零外部资产**——不加载任何外部图片、模型、音频或字体文件，全部内容全程序化生成。仓库历史上曾包含少量第三方官方宣传图的裁片，仅用于当时的建模管线分析，**现已全部移除**，移除清单见 **[docs/ASSETS.md](docs/ASSETS.md) 第 7 节**。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建（tsc --noEmit && vite build）
npm run preview  # 预览构建产物
```

## 玩法机制说明（虚构与简化声明）

以下机制是**有意的设计选择而非实现疏漏**，在此显式声明，免生歧义：

- **踏板过载断裂 → 紧急制动安全冗余（虚构机制，2026-10-15 改版）**：持续满踏板力（b≥0.98）会累积过载并「踩断」刹车踏板。断裂后**踏板力归零（驾驶员踩空）、车辆不再翻滚**，由安全冗余回路以满载 **1/4 力度（2.70 m/s² ≈ 0.275g）** 接管拖停。真实制动系统的失效模式是热衰减 / 助力消失 / 气阻，踏板不会因持续深踩而机械断裂；冗余制动的强度也因车而异——本机制是**纯游戏化高潮设计**。结算语义：**冗余刹停 = 判负**（制动系统已失效，「侥幸逃生」≠ 成功刹停），计分 0 且不写入本机最佳；「翻滚」演出只保留给撞路障。
- **路障距离（玩法参数，1300m）**：赛道可用距离由 2600m 收紧为 **1300m**，使三档结局全部可达（Node 同源仿真标定）：正常刹停 834m（余 466m）｜满踩断裂冗余拖停 1107m（余 193m）｜额外巡航 300m 再切入 → 撞障。这是「氛围驾驶 + 计分」定位下的取舍，非拟真逃生场景。
- **单质点纵向模型（知情简化）**：整车按单质点计算，不区分前后轴载荷转移与抱死，隐含「完美 ABS + EBD」；对直线刹停玩法是合理简化。
- **路障质量（游戏化夸张）**：碰撞世界中路障刚体 650kg/块，低于真实混凝土隔离墩（1–2 吨），翻飞观感偏夸张。
- **热衰减（拟真简化，且当前在单局内不可达）**：制动温度按摩擦功积分，一次满刹可感知升温、连续重刹触发 ×0.85 衰减，但未建模刹车盘热容与通风细节。**已知边界**：实测单把 200→0 满刹峰值温度 0.494 < 阈值 1.0，且加速段风冷（18s × 0.25/s）会把跨局残留完全抹平——因此热衰减在当前单局玩法中不会真正触发（不会惩罚正确操作）。它要进入博弈需配合「连续多刹」耐力模式，已登记为后续项。
- **自由视角（覆盖层，非新机位）**：拖拽 = 环绕 / 车内转头，滚轮 = 缩放，双击 = 回正；偏移叠加在既有阻尼机位系统之上，切机位时归零。
